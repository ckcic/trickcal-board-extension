# 🎨 트릭컬 노트 보드 확장 프로그램 (Trickcal Board Extension)

[트릭컬 노트](https://note.trickcal.com/board) 웹사이트의 **사도별 보크(상급 크레파스) 진행도 확인 및 스탯·성격·성급별 필터링**을 지원하는 Chrome 확장 프로그램입니다.

---

## ✨ 주요 기능

- 📊 **사도별 보크 칠하기 진행도 뱃지**
  - 각 사도 카드에 `1~3차 전체 보크 수`, `획득한 보크 수`, `남은 보크 수`를 직관적으로 표시합니다.
  - 마우스 호버 시 1차/2차/3차 보드별 및 스탯별 상세 진행도를 툴팁으로 확인 가능합니다.
- 🎯 **스탯별 작업 필터 & 실시간 하이라이트**
  - 체력, 물공, 마공, 물방, 마방, 치명, 치피, 치저, 치피저 등 특정 스탯을 선택하면 **해당 스탯의 보크 타일에 선명한 빨간 테두리**가 표시됩니다.
  - 황크(최상급 크레파스) 타일 및 일반 타일은 정확히 제외되고 보크 타일만 타겟팅됩니다.
- 🔍 **다양한 필터링 옵션**
  - **보크 상태 필터**: 전체 / 미완료 / 완료
  - **보드 기준 필터**: 전체 / 1차 / 2차 / 3차 (선택한 차수의 보드만 카드 내에 깔끔하게 표시)
  - **태생 성급 필터**: 전체 / 3성 / 2성 / 1성 (보드 수가 적은 태생 1성 사도 집중 관리)
  - **성격별 필터**: 순수 / 냉정 / 광기 / 활발 / 우울 / 공명
- 📈 **스탯별 종합 칸 수 & 증가 수치 요약 바**
  - 현재 필터 조건에 맞춰 스탯별 총 칸 수, 칠한 칸 수, 남은 칸 수가 실시간으로 집계됩니다.
  - 호버 시 **1칸당 증가 수치(체력 +199, 물마공 +13, 물마방 +20, 치명/치피/치저/치피저 +15)**와 총 증가량이 안내됩니다.
- 🛡️ **개인정보 보호 & 보안**
  - 사용자의 API 토큰이나 개인 식별 정보는 일체 저장하거나 외부로 전송하지 않으며, 오직 브라우저 내부 메모리에서만 안전하게 연산됩니다.

## 🚀 설치 방법

### 일반 사용자 (ZIP 다운로드 설치)

1. [Releases](../../releases) 탭에서 최신 버전의 `trickcal-board-extension.zip` 파일을 다운로드하고 압축을 풉니다.
2. Chrome(또는 Edge/웨일/Brave) 브라우저 주소창에 `chrome://extensions` 를 입력하여 확장 프로그램 관리 페이지로 이동합니다.
3. 우측 상단의 **[개발자 모드]** 스위치를 켭니다.
4. 좌측 상단의 **[압축해제된 확장 프로그램을 로드합니다]** 버튼을 클릭하고 압축을 푼 폴더(`dist` 또는 압축 해제된 폴더)를 선택합니다.
5. [트릭컬 노트 보드 페이지](https://note.trickcal.com/board)에 접속하시면 즉시 확장 프로그램이 활성화됩니다!

## 🛠️ 개발 및 빌드 (Developer)

```bash
# 1. 의존성 설치
npm install

# 2. 단위 테스트 실행
npm test

# 3. 확장 프로그램 빌드 (dist/ 생성)
npm run build

# 4. 배포용 ZIP 패키징 (trickcal-board-extension.zip 생성)
npm run package
```
