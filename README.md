[트릭컬 노트(note.trickcal.com/board)](https://note.trickcal.com/board) 웹사이트에서 **사도별 보크(상급 크레파스) 및 일반칸 칠하기 진행도 실시간 확인, 스탯 타일 하이라이트, 다차원 필터링 및 정렬**을 지원하는 Chrome 확장 프로그램입니다.

---

## ✨ 주요 기능

### 1. 📊 사도별 보크(상급칸) & 일반칸 실시간 뱃지
- **상급칸(보크) 진행도 뱃지:** 사도 카드 상단에 `획득한 보크 / 전체 보크 (남은 수)`를 즉시 표시하며, 완료 시 초록색 완료 표시(`✓`)로 전환됩니다.
- **마우스 호버 상세 툴팁:** 뱃지에 마우스를 올리면 1차/2차/3차 보드별 및 9개 스탯별 상세 진행도 현황이 전역 포털로 부드럽게 펼쳐집니다.
- **일반칸 상세 팝업 & 창 고정(Pin) 지원:**
  - 일반칸 뱃지(`일반칸 칠한수/전체수 (%)`)를 통해 일반칸 진행률을 직관적으로 확인.
  - 마우스 호버 시 차수별 달성률, 기본(하급) 및 강화(중급) 크레파스 칸 수, 스탯별 획득/미획득 상세 테이블 제공.
  - **클릭 시 팝업 고정:** 마우스가 벗어나도 창이 닫히지 않고 자유롭게 스크롤 및 비교 가능.

### 2. 🎯 스탯별 작업 필터 & 실시간 타일 하이라이트
- 체력, 물공, 마공, 물방, 마방, 치명, 치피, 치저, 치피저 등 집중 작업할 스탯을 클릭하면 **해당 스탯의 보크 타일에 선명한 빨간색 테두리(미완료) 또는 주황색 테두리(완료)**가 실시간 표시됩니다.
- 황크(최상급 크레파스) 타일 및 일반 타일은 정확히 제외되고 보크 타일만 선별 타겟팅됩니다.

### 3. 🔍 다차원 필터링 & 검색 시스템
- **보크 상태 필터:** 전체 / 미완료 / 완료
- **표시 보드 필터:** 전체 / 1차 / 2차 / 3차 (선택한 차수의 보드만 카드 내에 깔끔하게 축소 표시)
- **해금 관문 필터:** 전체 / 1차 / 2차 / 3차 (사도가 현재 해금한 보드 관문 단계별 필터링)
- **초기 성급 필터:** 전체 / 3성 / 2성 / 1성 (보드 수가 적어 빠른 완성이 가능한 태생 1성·2성 집중 관리)
- **성격별 필터:** 순수 / 냉정 / 광기 / 활발 / 우울 / 공명 (스프라이트 아이콘 지원)
- **사도 이름 검색 통합:** 사이트 본래의 사도 검색창을 필터 패널 내부로 매끄럽게 통합.

### 4. 🔀 스마트 사도 정렬 (Sort)
- **이름순:** 가나다 오름차순(▴) ↔ 내림차순(▾)
- **보드 해금 순:** 3관문 해금 사도 우선(▾) ↔ 1관문 우선(▴)
- **초기 성급 순:** 태생 3성 우선(▾) ↔ 태생 1성 우선(▴)
- **성격순:** 순수 → 냉정 → 광기 → 활발 → 우울 → 공명(▴) ↔ 역순(▾)
- 정렬 기준이 동일할 경우 **한국어 가나다순 2차 정렬**이 자동으로 적용됩니다.

### 5. 📈 스탯별 총 칸 수 & 실시간 증가 수치 요약 바
- 패널 하단에 현재 필터 조건에 대응하는 9개 스탯별 총 칸 수, 칠한 칸 수, 남은 칸 수가 실시간 집계됩니다.
- 스탯별 카드 호버 시 **1칸당 고유 증가량(체력 +199, 물마공 +13, 물마방 +20, 치명 계열 +15)**과 현재/최대 스탯 증가량이 산출됩니다.

### 6. 🚀 최신 사이트 환경 호환 & 가상 스크롤(Virtuoso) 완벽 지원
- 트릭컬 노트 웹사이트의 `react-virtuoso` 가상 스크롤 시스템과 메인 월드 브리지로 직접 연동되어, 대량의 사도 카드 렌더링 시에도 버벅임이나 높이 튀는 현상 없이 매끄럽게 동작합니다.
- **최신 버전 자동 알림:** GitHub Releases와 연동되어 신규 버전 출시 시 패널 상단에 업데이트 알림 뱃지가 노출됩니다.

### 7. 🛡️ 무결성 & 개인정보 보안 (Zero-Telemetry)
- 사용자의 API 토큰, 인증 정보, 계정 식별자는 일체 저장하거나 외부 서버로 전송하지 않습니다.
- 모든 데이터 파싱 및 연산은 **브라우저 로컬 메모리(Client-side)** 내에서만 순수 함수로 안전하게 처리됩니다.

### 8. 🖍️ 보크 칸 클릭 및 경로 안내
- 보크 칸을 클릭하면 선택한 차수의 위치 보드, 선택 칸의 비용과 색칠 경로의 추가 비용을 표시합니다.
- 이미 칠한 칸과 열린 관문의 비용은 다시 더하지 않으며, 닫힌 선행 꽃잎의 물뿌리개·골드를 반영합니다.
- 황크·만개 칸은 원본 모달을 유지합니다. 작은 창에서도 카드와 팝업이 원본 고정 메뉴를 가리지 않습니다.
- 자세한 변경 사항은 [1.0.9 릴리스 노트](RELEASE_NOTES.md)를 참고하세요.

## 📥 설치 방법

### 개발 브랜치 베타: 만개·황크 재분배

사도별 보드의 확장 필터를 펼쳐 **만개·황크 재분배 (베타)**를 누르면, 사용한 황크를 자동 집계해 총 황크의 기본값으로 표시합니다. 추가 보유 황크(미사용)는 기본 0이며, 초기화 인원 상한과 단계별 목표·우선순위를 설정할 수 있습니다. 참고 이미지의 7단계는 수정 가능한 초기 예시이며, 단계 추가·삭제·순서 이동과 단계별 스탯·목표 %·전부 설정을 지원합니다. 같은 스탯을 여러 단계에서 나눠 올릴 수 있습니다. 현재 필터와 관계없이 보유 사도 전체의 전후 황크 스탯, 환급·사용 재화, 목표 부족량, 사도별 변경 지도와 칠할 칸 순서를 표시합니다. 실제 가용 예산에는 추가 보유량과 초기화 대상의 환급분만 포함합니다.

- 초기화 시 열린 관문·꽃잎과 기본 색칠된 1차 시작 칸은 유지하고, 지워지는 칸의 크레파스 4종·골드만 환급합니다. 기존 일반칸은 복구하며, 보크는 연결과 설정한 목표에 필요한 만큼 다시 칠합니다.
- 3차 목표까지의 경로도 1차 시작 칸부터 연결하며, 열린 관문까지 가는 2차 경로를 생략하지 않습니다. 경로는 황크·보크 소모가 적은 순으로 선택합니다.
- 막힌 경로는 색칠 여부와 관계없이 방어력(물방·마방)·치저 황크칸을 거쳐야 하는 경로입니다. 같은 스탯의 보크는 차단하지 않습니다. 포함을 끄면 해당 황크를 피하며 기존 칸을 자동으로 지우지는 않습니다. 일반칸 복구 경로는 별도로 유지합니다. 방어력·치저를 새로 칠할 단계에서는 포함을 켜세요.
- 목표 입력은 공격력 6%·나머지 8% 단위로 증감합니다. 직접 입력한 목표는 한 칸 단위로 올림하며, 보유 사도의 스탯별 최대 황크 칸 수를 차수별 전체·현재 해금 범위로 표시합니다.
- 황크·보크 단계를 원하는 순서로 배치합니다. 보크는 단계마다 1차 / 1~2차 / 1~3차의 누적 칸 수를 지정합니다. 겹치는 누적 목표는 중복 합산하지 않습니다. 보유량(미입력 시 0)+환급분이 사용 상한이며, 보크 단계 전에는 일반칸 복구·연결에 필요한 보크만 사용합니다. ‘전부’ 입력에는 해당 경로 범위의 실제 목표 수치를 표시합니다.
- ‘관문 개방 포함’을 켠 단계는 잠긴 보드까지 연결하고 필요한 관문의 골드·전용 재화를 표시합니다. 전용 재화 보유량과 개방 자격은 별도 확인합니다. 미개방 꽃잎은 물뿌리개·골드 비용을 포함해 개방합니다. 물뿌리개는 환급되지 않습니다. 초기화를 먼저 모두 진행하고, 환급 외 필요한 재화를 준비한 뒤 표시 순서대로 색칠하는 계획입니다.
- 결과는 단계별 목표 요약·스탯별 차수 배치·사도별 작업 표로 표시하며, 사도 이름을 누르면 지도를 펼칩니다. 재화는 아이콘, 보크 결과는 원본 정수 스탯 합계와 칸 수로 표시합니다. 추천안 계산 전에도 인원별 그래프를 계산해 초기화 상한을 정할 수 있습니다. 황크는 %, 보크는 지정 차수의 정수 스탯 변화로 비교합니다. 보크 목표 기준선은 기본 칸 수치로 환산합니다.
- 스탯 목표 기본값은 예시입니다. 초기화 후보 8명 이하는 조합을 전수 비교하고, 더 큰 경우에는 빠른 탐색(상한별 최대 3조합)을 기본으로, 상세 탐색(더 많은 조합)을 선택할 수 있습니다. 황크·보크 대체 경로와 소규모 칸 배분의 대안도 비교하지만 전역 최적해·최소 초기화 인원을 보장하지 않습니다.
- 게임·노트 데이터에 자동 적용하지 않습니다. 입력과 결과는 메모리에서만 처리하며, 데이터가 새로 수신되거나 다른 탭으로 이동하면 계산 창을 닫아 오래된 계획 사용을 방지합니다.

### 일반 사용자 (ZIP 다운로드 수동 설치)

1. [Releases](../../releases) 탭에서 최신 버전의 `trickcal-board-extension.zip` 파일을 다운로드하고 압축을 풉니다.
2. Chrome (또는 Edge, 웨일, Brave 등 Chromium 계열 브라우저) 주소창에 `chrome://extensions` 를 입력하여 확장 프로그램 관리 페이지로 이동합니다.
3. 우측 상단의 **[개발자 모드]** 스위치를 켭니다.
4. 좌측 상단의 **[압축해제된 확장 프로그램을 로드합니다]** 버튼을 클릭하고 압축을 푼 폴더(또는 `dist` 폴더)를 선택합니다.
5. [트릭컬 노트 보드 페이지(note.trickcal.com/board)](https://note.trickcal.com/board)에 접속하시면 확장 프로그램이 자동으로 활성화됩니다!

## 🛠️ 개발 및 빌드 (Developer Guide)

본 프로젝트는 TypeScript 5.x 및 Node.js 내장 테스트 러너(`node --test`), `esbuild` 기반으로 구성되어 있습니다.

```bash
# 1. 의존성 패키지 설치
npm install

# 2. 단위 테스트 실행
npm test

# 3. TypeScript 타입 검사 및 개발용 빌드 (dist/ 생성)
npm run build

# 4. 소스코드 변경 감지 및 자동 빌드 (Watch 모드)
npm run watch

# 5. 배포용 프로덕션 빌드 및 ZIP 패키징
npm run package
```

### 아키텍처 구조

```text
src/
├── bridge/          # MAIN world와 ISOLATED world 간 안전한 통신 및 Virtuoso 가상 목록 연동
│   ├── interceptor.ts   # fetch/XHR API 응답 데이터 가로채기
│   ├── contentBridge.ts # postMessage 통신 브리지
│   └── virtualGrid.ts   # react-virtuoso 가상 목록 필터/정렬 어댑터
├── domain/          # 순수 비즈니스 로직 및 스탯/진행도 계산 (Chrome API 독립)
│   ├── boardProgress.ts # 보크/황크/일반칸 진행도 계산
│   ├── normalStatValues.ts # 태생 성급별 일반칸 고정 스탯 상승량 테이블
│   ├── filters.ts       # 다차원 필터 판정 로직
│   ├── listSelection.ts # 가상 목록 정렬 및 사도 ID 선별
│   ├── updateChecker.ts # 신규 릴리스 버전 확인
│   └── types.ts         # TypeScript 타입 정의
├── ui/              # DOM 하이라이팅, 뱃지 주입, 필터 패널 오케스트레이션
│   ├── boardEnhancer.ts # 사도 카드 뱃지 주입 및 가시성 제어
│   ├── filterPanel.ts   # 4단 필터/정렬 컨트롤 패널 및 스탯 요약 바
│   ├── normalStat.ts    # 일반칸 상세 진행도 팝업 및 고정(Pin) 모달
│   ├── badge.ts         # 보크 뱃지 및 전역 포털 툴팁
│   ├── tileHighlight.ts # 보드 타일 실시간 테두리 하이라이트
│   └── styles.css       # 네임스페이스 격리 스타일시트
└── content.ts       # ISOLATED world 엔트리포인트 및 DOM MutationObserver
```
